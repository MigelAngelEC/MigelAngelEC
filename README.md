## 2 · Cofres Ecuador

<a href="https://www.cofresecuador.com/"><b>Cofres Ecuador</b></a> is a funeral-services company in Ecuador, and I build the platform that runs its operations: an admin panel plus client, provider and employee portals.

- **HR and payroll** under Ecuadorian labor law: IESS contributions, reserve funds, 13th and 14th salaries, vacations, regional severance calculator (Sierra, Costa, Amazonía)
- **Suppliers and payments:** invoices with SRI validation, automatic withholdings, payment tracking with receipts
- **Communications:** WhatsApp Business inbox and templates, React Email with delivery tracking, real-time in-app notifications
- **Operations:** roles and permissions, audit logging, Excel import and export, PDF/Word/Excel documents, AI-assisted workflows
- **Infrastructure:** migrated in July 2026 from a hosted cloud stack to a fully local one (Supabase CLI, Mailpit, Cloudflare tunnel for webhooks), with an end-to-end suite of 94 tests verifying the restore against production

## 3 · Acodear

<a href="https://www.acodear.com"><b>Acodear</b></a> is a Spanish-language coding school I co-founded with three partners. I work on programming, DevOps and full stack.

- **[Acodear Academy](https://www.acodear.com):** programming courses with exercises that run in the browser. A Flask service executes student code in isolated Docker containers and returns the test results, and an admin app handles multi-language course authoring
- **Acodear AI:** a universal iOS, Android and web learning app with AI-assisted lessons, an interactive sandbox and a community space, backed by a Bun + Hono + Postgres API
- **[Acodear Mentorhood](https://mentorhood.acodear.com):** mentoring and consulting that helps students speed up their careers
