[![Stars](https://img.shields.io/github/stars/miguel50flowers/openvpn-mac-fix?style=flat-square&color=8B5CF6)](https://github.com/miguel50flowers/openvpn-mac-fix/stargazers)
[![Swift](https://img.shields.io/badge/Swift-macOS%2013%2B-orange?style=flat-square&logo=swift&logoColor=white)](https://github.com/miguel50flowers/openvpn-mac-fix)

SwiftUI menu-bar app + privileged helper that **auto-restores internet** after disconnecting from any of **17 supported VPN clients**. XPC architecture, DNS/DHCP/firewall cleanup, real-time status, Sparkle auto-updates. Distributed via DMG, .pkg and **Homebrew**. *Shared with my [work profile](https://github.com/miguel50flowers).*

<td width="50%" valign="top">

### `docker-maker`
[![docker-maker repo card](https://github-readme-stats.vercel.app/api/pin/?username=MigelAngelEC&repo=docker-maker&hide_border=true&theme=tokyonight)](https://github.com/MigelAngelEC/docker-maker)

[![Node](https://img.shields.io/badge/Node-TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)](https://github.com/MigelAngelEC/docker-maker)
[![CLI](https://img.shields.io/badge/CLI-tool-8B5CF6?style=flat-square&logo=docker&logoColor=white)](https://github.com/MigelAngelEC/docker-maker)

CLI tool (Node + TypeScript) that **auto-generates Dockerfiles and `docker-compose.yml`** from project structure. Detects stack (Node/Python/etc.), suggests sensible defaults, scaffolds multi-service compose files. Built to remove the repetition of containerizing every new side project.

## Selected work / Trabajo destacado

<table>
<tr>
<td width="50%" valign="top">

### Cofres Ecuador · 6-service fintech architecture

Multi-portal financial side project — 4 frontend portals + 1 backend API + 1 database service.

- **`backend-system`** — Express + TypeScript API with **JWT/OAuth** auth, centralized audit logging, role/permission management
- **`db-system`** — Reproducible **PostgreSQL** in `docker-compose` (single source of truth schema)
- **4 frontends** — `admin-frontend`, `clients-frontend`, `providers-frontend`, `employees-frontend` (Next.js 16 · React 19)

Stack: **Next.js 16** · **TypeScript** · **Express** · **PostgreSQL** · **Docker compose** · **JWT/OAuth** · audit + RBAC.

</td>
<td width="50%" valign="top">

### FocusLoop · native iOS/macOS productivity

Native iOS/macOS app for **focus sessions and habit tracking**. Built on the modern Apple stack — no cross-platform shortcuts.

- SwiftUI views, SwiftData persistence, Swift Concurrency for timers
- Cross-device sync (iCloud) for sessions and progress
- Notifications, widgets, Live Activities

Stack: **Swift 5.9** · **SwiftUI** · **SwiftData** · **Swift Concurrency** · **WidgetKit**.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Creatix · YouTube creator tooling

Suite of tools built **from a creator's perspective**: content planning, channel admin, analytics. Two repos working together.

- **`creatix`** — public-facing app (content planning, idea capture, scheduling)
- **`creatix-admin`** — admin dashboard for channel ops

Started as a personal-use tool, evolving into a product. Scratching my own itch from running my own channel.

Stack: **Next.js 16** · **React 19** · **TypeScript** · **Tailwind**.

</td>
<td width="50%" valign="top">

### my-portfolio · dual-identity 3D site

Interactive 3D portfolio at [maecly.com](https://www.maecly.com/) presenting **two facets**: Developer and Content Creator. Custom Three.js scenes, GLSL shaders, animated transitions per identity mode.

- Next.js 16 app router with React 19
- React Three Fiber + Drei helpers
- Custom GLSL materials and post-processing
- Routing tied to identity selector

Stack: **Next.js 16** · **Three.js** · **React Three Fiber** · **GLSL** · **TypeScript**.
